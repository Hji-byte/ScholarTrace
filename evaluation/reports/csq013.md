# Literature Review

Which benchmarks and metrics have been proposed to evaluate hallucination in vision-language models, and what aspects of model behavior does each benchmark test?

## Summary
The evaluation of hallucination in vision-language models (VLMs) has led to the development of diverse benchmarks and metrics that target specific aspects of model behavior, ranging from basic object presence to complex relational reasoning and domain-specific generation [1, 3, 5, 7]. Early frameworks primarily relied on text-axis question-answering to assess object hallucinations, but recent advancements have introduced vision-axis manipulations, triplet-level evaluations, and specialized metrics for voluntary imagination and medical domains [1, 2, 3, 7]. Despite these advancements, disentangling the multimodal sources of hallucination and accurately evaluating open-ended generative tasks remain ongoing challenges [1, 2].

## Object-Level and Question-Answering Benchmarks
Many foundational benchmarks evaluate object hallucination using discriminative or generative question-answering formats. POPE and CIEM utilize discriminative yes/no questions to probe for object presence, measuring performance via accuracy, precision, and recall [1]. POPE extends the CHAIR metric, which was originally designed to assess object hallucination in sentence-level image captions [4]. Building on this, NOPE quantitatively assesses object hallucination through visual question answering based on the POPE technique [4]. To capture open-ended generation, the AMBER benchmark incorporates generative question types, extracting objects from model captions to compare against ground-truth image objects [1]. For free-form and lengthy answers in open-ended visual question answering, FaithScore provides a reference-free metric for fine-grained hallucination evaluation [2, 4]. Similarly, Throne serves as an object-based benchmark tailored for the free-form generations of large vision-language models [2]. However, benchmarks that rely solely on manipulating text questions and answers, such as POPE, CIEM, and AMBER, struggle to disentangle the distinct visual and textual sources of hallucination in multimodal models [1].

## Vision-Axis and Change-Aware Evaluation
To address the limitations of text-axis evaluations, the BEAF benchmark introduces a vision-axis approach by manipulating visual scenes, such as removing and inpainting objects, and observing the before-and-after changes in model answers [1]. This methodology tests the model's ability to perceive visual changes and visualize image-wise object relationships [1]. BEAF introduces change-aware metrics, including True Understanding (TU), IGnorance (IG), StuBbornness (SB), and InDecision (ID) [1]. The InDecision metric specifically measures the rate at which models incorrectly alter their answers regarding unmanipulated objects, highlighting a failure to ground predictions in the visual input [1]. Evaluations using BEAF reveal that models achieving high accuracy on traditional text-axis benchmarks may still suffer from significant hallucination, as evidenced by TU scores that are substantially lower than traditional accuracy metrics [1].

## Relationship, Attribute, and Knowledge-Based Benchmarks
Beyond basic object presence, recent frameworks categorize and test hallucinations involving attributes, inter-object relationships, and world knowledge. R-Bench evaluates vision relationship hallucinations using image-level questions to test the existence of relationships and instance-level questions to assess local visual comprehension [5]. QA-VisualGenome provides a fine-grained benchmark using yes-or-no questions to specifically evaluate attribute and relation hallucinations of objects [6]. To assess cognition-based hallucinations, QA-FB15K is built on a multimodal knowledge graph, testing a model's ability to leverage world knowledge for specific entities like the names of people and famous buildings [6]. Furthermore, the Tri-HE framework measures both object and relation hallucinations simultaneously by evaluating (object, relation, object) triplets extracted from model responses [7]. Evaluations with Tri-HE indicate that relation hallucination is a more severe issue than object hallucination in existing large vision-language models [7].

## Domain-Specific and Generative Task Benchmarks
Specialized benchmarks have also been developed to evaluate hallucinations in specific domains and generative tasks. In the medical domain, Med-HallMark evaluates hallucinations using BertScore and ROUGE metrics for open-ended questions across four dimensions: conventional medical, confidence-weakening, counterfactual, and image depiction questions [3]. The MediHall Score offers a fine-grained metric for medical text hallucinations across Med-VQA and Image Report Generation tasks by assessing answers at the sentence or multi-dimensional level [3]. For voluntary imagination tasks like story writing, VOPE assesses grounding behavior and presence judgments regarding the model's own generated objects using recheck-based questions [2]. VOPE introduces the Hal-D metric for the hallucination rate in factual descriptions and Hal-I for the grounding failure rate on voluntarily imagined objects [2]. Notably, the CHAIRi metric has been shown to overestimate hallucinations in writing tasks when compared to the Hal-D metric [2]. Additionally, SHALE provides a scalable benchmark for fine-grained hallucination evaluation in large vision-language models, while INFACT serves as a diagnostic benchmark for induced faithfulness and factuality hallucinations in Video-LLMs [2].

## Limitations and Open Problems
While current evaluation frameworks have expanded from simple object presence to complex relational and domain-specific reasoning, several limitations persist. Benchmarks relying exclusively on text-axis manipulations struggle to isolate whether hallucinations originate from visual misperception or textual priors [1]. Furthermore, evaluating open-ended and voluntary imagination tasks remains difficult, as traditional metrics like CHAIRi may overestimate hallucinations in creative contexts, necessitating specialized recheck-based frameworks like VOPE [2]. Future work must continue to develop unified metrics that can simultaneously assess object, attribute, and relation hallucinations across both factual and generative modalities without relying on rigid question-answering constraints.
