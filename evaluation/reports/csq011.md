# Literature Review

What are the main neural representations for novel-view synthesis, including neural radiance fields and 3D Gaussian splatting, and what are their computational trade-offs?

## Summary
Novel-view synthesis relies primarily on implicit neural representations, such as Neural Radiance Fields (NeRF) [1, 2, 3, 4, 5, 8], and explicit representations, such as 3D Gaussian Splatting (3DGS) [2, 3, 4, 5, 9]. While NeRF offers compact models and high-quality renderings, it suffers from slow training and rendering due to dense volumetric sampling [1, 2, 4, 8]. Conversely, 3DGS achieves real-time rendering and faster training by utilizing explicit, sparse primitives, but at the cost of significantly higher memory consumption [1, 3, 4, 5, 9]. Recent research focuses on hybrid architectures [4], tensor factorization [1], and parameter compression [4, 8] to balance these computational trade-offs and overcome the inherent limitations of both paradigms.

## Primary Neural Scene Representations
The dominant implicit representation is the Neural Radiance Field (NeRF), which models scenes using Multi-Layer Perceptrons (MLPs) to predict density and color for volumetric rendering [1, 2, 3, 4, 5, 8]. To address the computational overhead of MLPs, alternative implicit representations such as Multiresolution Hash Encoding have been proposed to accelerate rendering [2]. Another alternative, NeurMiPs, represents 3D scenes using a mixture of learnable planar experts, combining rectangular shapes with neural radiance fields for efficient ray-casting-based rendering [7].

In contrast, 3D Gaussian Splatting (3DGS) employs an explicit representation consisting of a set of learnable 3D Gaussian ellipsoids characterized by attributes such as position, rotation, opacity, scale, and color [2, 3, 4, 5, 9]. By bypassing volumetric rendering in favor of differentiable point-based splatting, 3DGS achieves novel view synthesis quality similar to NeRFs while enabling real-time rendering [2, 3, 4, 5, 9]. Furthermore, the explicit nature of 3DGS facilitates downstream tasks such as dynamic reconstruction and geometry editing [5].

## Computational Trade-offs: Speed, Memory, and Quality
NeRF produces high-quality renderings with compact model sizes but is hindered by slow rendering and training speeds [1, 2, 3, 4, 5, 8]. This computational overhead stems from the need to densely sample the entire volume, including empty spaces, which scales poorly with scene size [1, 9]. 

3DGS significantly reduces training and rendering time costs by generating a sparse adaptive scene representation that focuses only on rendering known primitives, thereby eliminating the need to sample empty spaces [1, 8, 9]. This enables high-speed rendering on the GPU through differentiable rasterization [1, 8, 9]. However, 3DGS suffers from a much higher memory footprint and substantial storage requirements [2, 3, 4, 5, 9]. Each Gaussian requires numerous parameters—such as 59 parameters per Gaussian, including 48 for view-dependent color via spherical harmonics—to model anisotropic shapes and view-dependent effects [1, 4]. Additionally, while 3DGS produces high-quality renderings with many input views, its performance drops significantly in few-shot scenarios where only a limited number of views are available [2].

Modifications to the representation also introduce specific trade-offs. For instance, encoding color information with feature vectors instead of spherical harmonics in 3DGS increases model capacity and halves the number of Gaussians per scene, but introduces a computational trade-off where rendering time scales linearly with the feature vector dimension [3]. In specialized domains like X-ray novel view synthesis, tuning the number of final 3D Gaussians and initialized intervals involves balancing computational complexity, memory cost, and inference speed to find optimal performance thresholds [6].

## Acceleration and Compression Techniques
To address the large model size and memory overhead of 3DGS, researchers have developed various compression and acceleration techniques. Parameter compression techniques using vector quantization and factorized coordinates, such as F-3DGS, utilize tensor factorization to achieve a significant reduction in storage costs while maintaining comparable rendered image quality [1, 4].

Hybrid architectures have also been proposed to bridge the gap between rendering efficiency and compact representation. Hybrid Radiance Fields (HyRF) address the memory bottleneck of 3DGS by combining explicit Gaussians that store only essential properties with implicit neural fields to preserve high-frequency spatial details [4]. This approach reduces model size by 20× compared to standard 3DGS while maintaining real-time performance [4]. HyRF also utilizes a visibility pre-culling strategy to eliminate points not projected onto the image plane, thereby reducing the computational overhead of querying neural fields [4]. However, compressing 3DGS models using purely neural fields struggles to capture high-frequency spatial variations in Gaussian properties, leading to degraded reconstruction of fine details [4]. Furthermore, while compression schemes aim to reduce memory overhead for applications like network streaming and mobile rendering, they face limitations in aggressively compressing the Gaussian representations without sacrificing quality [8].

## Limitations and Open Problems
Despite significant advancements, several limitations remain in neural representations for novel-view synthesis. NeRF-based methods continue to struggle with high computational costs and poor scalability with scene size due to dense volumetric sampling [1, 2, 3, 4, 5, 8, 9]. While 3DGS resolves the rendering speed bottleneck, its massive memory footprint remains a critical barrier for resource-constrained environments like mobile rendering and network streaming [1, 4, 8]. Current compression techniques, including purely neural field approaches and aggressive parameter quantization, often fail to capture high-frequency spatial details or face inherent limitations in compression rates [4, 8]. Additionally, 3DGS exhibits a notable performance degradation in few-shot settings, indicating a reliance on dense input views for high-quality reconstruction [2]. Future research must continue to explore hybrid representations and advanced compression schemes that can effectively balance the trade-off between high-fidelity rendering, compact memory storage, and real-time computational efficiency.
