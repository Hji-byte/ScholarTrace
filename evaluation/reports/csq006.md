# Literature Review

What are the main parameter-efficient fine-tuning methods, and how do they reduce trainable parameters while preserving downstream performance?

## Summary
Parameter-efficient fine-tuning (PEFT) methods adapt large pre-trained models by freezing the vast majority of parameters and tuning less than 1% of them, alleviating storage burdens and mitigating overfitting while maintaining downstream performance [3, 6]. These methods are broadly categorized into addition-based approaches, which introduce new modules, and selective in-situ or reparameterization-based methods, which fine-tune a subset of original parameters [4, 6]. While PEFT can match or exceed full-model fine-tuning performance with significantly reduced memory costs [2], trade-offs exist between parameter reduction, representational capacity, and actual memory consumption due to implementation overheads [3, 4].

## Categories and Mechanisms of Parameter-Efficient Fine-Tuning
PEFT methods are primarily divided into addition-based and selective in-situ adaptation (or reparameterization-based) categories [4, 6]. Addition-based methods attach additional trainable parameters to the backbone. Examples include Adapters, which add modules to each transformer layer, and Prompt or Prefix tuning, which prepend tunable soft tokens to the input or hidden layers [7]. Selective update and reparameterization methods fine-tune only a subset of the original parameters. BitFit achieves this by tuning only the bias terms while keeping all other parameters frozen [1, 7]. Low-Rank Adaptation (LoRA) reduces trainable parameters by replacing full-rank weight updates with low-rank matrices [1, 7].

Beyond these primary categories, various architectural and algorithmic mechanisms have been developed to minimize trainable parameters. GRASP partitions token representations into groups and learns shared scaling and shifting parameters for each group, avoiding additional matrix multiplications [1]. Its stochastic variant, StochGRASP, learns Gaussian perturbation distributions to improve robustness against hardware-level noise [1]. Quantum-PEFT utilizes quantum unitary parameterizations with Pauli parameterization, enabling logarithmic scaling of trainable parameters with respect to the ambient dimension [5]. PiCa reduces parameters by projecting gradients onto the principal column space spanned by pre-trained weights and employing a weight-sharing method [3]. Adaptive methods like AdaPEFT select a subset of parameters using a Hessian-informed approach that solves a 0-1 knapsack problem via Pareto optimality [2]. Furthermore, methods like Singular Vectors-guided Fine-Tuning (SVFT) leverage the spectral structure and geometry of pre-trained weights to achieve further parameter efficiency [3]. Variants of LoRA, such as DoRA, decompose weights to match or surpass LoRA's performance with half the parameters, while VeRA trains small scaling vectors to achieve comparable performance with up to four times fewer parameters [3]. Unstructured parameter selection methods, such as GPS and SPT, selectively fine-tune only the subsets of parameters most critical for a specific target task [4, 6].

## Performance Preservation and Evaluation
PEFT methods adapt large pre-trained models by tuning less than 1% of parameters, which eases optimization difficulty and mitigates overfitting while maintaining or improving downstream performance [3, 6]. PEFT approaches can match or exceed the downstream performance of full-model fine-tuning (FMT) while significantly reducing memory costs; for instance, LoRA uses five times less memory than FMT on LLAMA2-7B [2]. In evaluations on the GLUE benchmark using RoBERTa-base, FMT achieved an average accuracy of 86.4%, LoRA achieved 87.2%, and BitFit achieved 85.2% [2]. 

Advanced methods further preserve or enhance performance under strict parameter budgets. Quantum-PEFT maintains competitive performance while achieving a 5 to 25-fold reduction in trainable parameters compared to LoRA [5]. PiCa achieves significantly better performance than baseline methods with similar parameter budgets, such as rank-1 LoRA and DoRA [3]. SVFT leverages the geometry of pre-trained weights to achieve further parameter efficiency without degrading performance, overcoming the limitations of randomly initialized low-rank matrices in standard LoRA [3]. Despite the steady increase in new PEFT methods, LoRA-based variants remain predominantly employed in practice for autoregressive large language models due to their high efficiency and popularity [8].

## Trade-offs in Parameter Reduction and Memory Efficiency
While PEFT methods significantly reduce the number of trainable parameters, there are notable trade-offs between parameter reduction, performance preservation, and memory efficiency. Addition-based PEFT methods offer strong memory efficiency but often have limited representational capacity for fine-grained adaptation compared to selective in-situ methods [4]. In low-rank adaptation, lowering the rank reduces trainable parameters but can cause significant performance degradation; variants like DoRA and VeRA address this by improving parameter efficiency without sacrificing performance [3]. 

Memory trade-offs also arise from implementation overheads. SVD-based methods like SVFT substantially reduce trainable parameters but can require up to 36% higher GPU memory than PiCa because the non-trainable singular vectors of the pre-trained weight matrix must be retained in memory during fine-tuning [3]. Similarly, sparse tuning paradigms, such as unstructured selection methods, suffer from higher memory usage due to mask-based implementations, resulting in memory consumption that remains comparable to full fine-tuning despite tuning only a small portion of parameters [4]. Additionally, traditional PEFT methods like Adapters introduce trainable parameters to task-agnostic positions based on human heuristics, whereas sensitivity-aware methods like SPT adaptively allocate parameters to task-specific important positions to better handle domain gaps [6].

## Limitations and Open Problems
Several limitations and open problems remain in parameter-efficient fine-tuning. Addition-based methods often lack the representational capacity required for fine-grained adaptation compared to selective in-situ approaches [4]. Lowering the rank in standard LoRA inevitably causes significant performance degradation, necessitating more complex variants like DoRA or VeRA [3]. Memory efficiency is not always guaranteed by parameter reduction; SVD-based methods incur high GPU memory overheads due to the retention of non-trainable singular vectors [3], and sparse tuning paradigms suffer from comparable memory consumption to full fine-tuning due to mask-based implementations [4]. Furthermore, traditional methods rely on human heuristics for parameter allocation, which neglects task-specific domain gaps, highlighting the need for more adaptive, sensitivity-aware allocation strategies [6]. Finally, while many novel methods are proposed, LoRA-based variants continue to dominate practical applications, suggesting a gap between theoretical parameter efficiency and practical deployment preferences [8].
