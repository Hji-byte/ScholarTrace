# Literature Review

Which metrics and benchmark protocols are used to evaluate uncertainty calibration in deep neural networks, and what failure modes do these metrics miss?

## Summary
The evaluation of uncertainty calibration in deep neural networks relies on metrics such as the Expected Calibration Error (ECE) and the Brier score [1, 2], alongside benchmark protocols utilizing datasets like CIFAR-10, CIFAR-100, and the Aerial Image Dataset [2]. However, standard metrics like ECE and the Detection Expected Calibration Error (D-ECE) suffer from significant limitations, including dependence on binning schemes, failure to account for false negatives, and inconsistent behavior under distribution shifts [1, 2]. To address these blind spots, recent research has proposed alternative metrics (e.g., QGC, SGC, EGCE) [1] and comprehensive frameworks that incorporate all prediction types, including missing predictions [3], and leverage test-time augmentation to maintain calibration under out-of-distribution conditions [2].

## Standard Metrics and Benchmark Protocols
The Expected Calibration Error (ECE) is a widely used metric that evaluates the bin-wise difference between accuracy and confidence, though it is not a proper scoring rule [2]. The Brier score is increasingly adopted as a proper scoring rule alternative to overcome ECE's limitations [1, 2]. Negative Log-Likelihood (NLL) loss, while a proper scoring rule, only evaluates predictions for the true class and is therefore not considered a strict calibration metric [2]. In object detection, the Detection Expected Calibration Error (D-ECE) serves as a threshold-based metric leveraging Intersection over Union (IoU) [1]. Benchmark protocols typically assess methods using datasets such as CIFAR-10, CIFAR-100, and the Aerial Image Dataset, incorporating scenarios with artificially and naturally induced distribution shifts as well as out-of-distribution (OOD) samples [2]. Additionally, entropy is utilized in evaluation frameworks to assess whether an object detector can successfully identify distributional changes [3]. Conceptually, uncertainty calibration in object detection is divided into local calibration, which addresses the confidence values of existing detections, and global calibration, which addresses the rate of false negatives [1].

## Limitations and Failure Modes of Existing Metrics
Standard calibration metrics exhibit several critical blind spots and failure modes. ECE suffers from intractability, dependence on the chosen binning scheme, and the ability to yield trivial uninformative solutions [2]. Furthermore, standard calibration error estimators are typically biased and inconsistent [5]. Binning-based calibration methods, such as histogram binning and isotonic regression, are inherently biased toward ECE evaluation, leading to artificially favorable results on this specific metric [2]. Log-Likelihood (LL) metrics are closely correlated with model accuracy, and current post-hoc calibration methods often restrict themselves to optimizing only a single specific metric [4]. 

In object detection, existing evaluation frameworks often fail to clearly define how to incorporate true positives, false positives, true negatives, and missing predictions into evaluation metrics [3]. The D-ECE metric acts as a local calibration metric with no sensitivity to false negatives [1]. It fails to show a consistent relationship with mean Average Precision (mAP) under different IoU threshold conditions and lacks robust sensitivity to varying proportions of representative detections [1]. Moreover, D-ECE exhibits inconsistent behavior under distribution shifts and incorrectly indicates worse calibration as model capacity and mAP performance increase [1]. Strong improvements in object detection performance, measured by mAP, do not translate proportionally to improved uncertainty calibration evaluation [1]. Finally, typical post-hoc calibration methods that only alter the confidence values of existing detections may be insufficient for global calibration evaluation in object detection scenarios [1]. Histogram binning, for instance, only improves local calibration metrics like D-ECE and fails to improve global calibration metrics such as QGC, SGC, and EGCE [1].

## Performance Under Distribution Shift and OOD Conditions
Distribution shifts in test data negatively impact uncertainty calibration performance, even when state-of-the-art calibration methods are applied [1, 2]. Histogram binning fails to improve uncertainty calibration metrics under these conditions because it relies on the training data distribution, which often differs from the test set distribution [1]. To address these challenges, test time augmentation methods, such as M/V-ATTA, have been proposed. These methods improve uncertainty calibration and out-of-distribution predictive entropy without affecting model accuracy, outperforming several state-of-the-art post-hoc calibration techniques under distribution-shift scenarios [2].

## Alternative Metrics and Comprehensive Frameworks
To address the blind spots of standard measures, recent frameworks propose novel uncertainty calibration metrics for object detection that explicitly incorporate the number of false negatives into their calculations [1]. A novel framework introduces three new metrics—QGC, SGC, and EGCE—that evaluate semantic and label uncertainty using IoU threshold-based evaluation similar to mAP [1]. These metrics demonstrate consistent relationships with mAP under varying IoU thresholds and robust sensitivity to different detection types, unlike the existing D-ECE metric [1]. Furthermore, comprehensive evaluation frameworks for object detectors assess calibration using proper scoring rules, calibration plots, and errors across all predictions (true positives, false positives, true negatives) as well as missing predictions (false negatives) to ensure unbiased evaluation [3].

## Limitations and Open Problems
Despite recent advancements, several limitations and open problems remain in evaluating uncertainty calibration. Standard calibration error estimators are typically biased and inconsistent, necessitating the introduction of frameworks based on proper calibration errors [5]. There is a crucial need for optimization frameworks that allow multiple metrics, including ECEs, to be considered simultaneously, rather than restricting post-hoc methods to a single metric [4]. Additionally, the evidence suggests a need to rethink the way calibration techniques are developed and applied, particularly regarding post-hoc strategies that only act on the confidence values of existing detections, which are insufficient for global calibration [1].
